
# EVT2 Gesture Set
## Raw evt2 streams of various gestures, compressed by transfer bandwidth limitations of USB_FS port on STM32 board.
Recordings are labeled as:

(subject distance from sensor) - (gesture type) - (gesture description) - (extra gesture description)

ex) close-wave-circle-CCW.bin is a close up recording of a wave type gesture moving in a circle, counter-clockwise
